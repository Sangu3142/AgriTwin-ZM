RELATIONSHIPS (textual)
=======================

  Main          -- creates    --> ConsoleUI
  Main          -- reflect    --> GuiApp        (only when --gui)
  ConsoleUI     -- composes  --> SupplyDemandEngine, StorageLossSimulator,
                                  PolicyEngine, ReportGenerator, FileHandler
  ConsoleUI     -- aggregates -> SimulationRecord (history list)
  GuiApp        -- composes  --> same 5 services
  GuiApp        -- contains  --> RecordRow (inner class)
  ReportGenerator -- delegates -> FileHandler  (structured export)
  ReportGenerator -- reads    --> SimulationRecord
  SupplyDemandEngine -- uses  --> Tomato (calculateWaste)
  StorageLossSimulator -- uses --> Maize, Tomato
  FileHandler   -- reads/writes -> SimulationRecord
  TestRunner    -- exercises -> all service / util classes
