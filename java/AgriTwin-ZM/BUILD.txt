============================================================
 AgriTwin-ZM v1.0 -- Build & Run Instructions
============================================================

PROJECT LAYOUT
--------------
AgriTwin-ZM/
  src/agritwin/Main.java           <- entry point (console default)
  src/agritwin/TestRunner.java     <- 18 PASS/FAIL unit tests
  src/agritwin/model/              <- Maize, Tomato, SimulationRecord
  src/agritwin/service/            <- SupplyDemandEngine, StorageLossSimulator,
                                      PolicyEngine, ReportGenerator
  src/agritwin/util/FileHandler.java
  src/agritwin/ui/ConsoleUI.java
  src/agritwin/ui/GuiApp.java      <- optional JavaFX GUI
  docs/UML_ClassDiagram.puml       <- PlantUML diagram source
  docs/UML_ClassDiagram.txt        <- text-only fallback diagram
  build.bat                        <- console build (no JavaFX needed)
  build_with_javafx.bat            <- full build (requires JavaFX SDK)


REQUIREMENTS
------------
- JDK 11 or newer (any vendor; OpenJDK is fine)
- Optional: JavaFX SDK 17+ (only for the GUI)

VERIFY THE JDK
--------------
> javac -version
> java  -version


BUILD (CONSOLE-ONLY, NO JAVAFX)
-------------------------------
From the AgriTwin-ZM/ directory:

> build.bat

Or manually (Windows cmd):
> if not exist out mkdir out
> dir /s /b src\*.java | findstr /v /i "GuiApp.java" /C:"DashboardController.java" /C:"components" > sources.txt
> javac -d out @sources.txt

Or on Linux / macOS:
> mkdir -p out
> find src -name "*.java" ! -name "GuiApp.java" ! -name "DashboardController.java" ! -path "*/components/*" > sources.txt
> javac -d out @sources.txt


BUILD WITH JAVAFX GUI
---------------------
1. Download JavaFX SDK from https://gluonhq.com/products/javafx/
2. Extract somewhere, e.g. C:\javafx-sdk-25\javafx-sdk-25.0.3
3. Set the env variable, then run the build script:

   > set JAVAFX_LIB=C:\javafx-sdk-25\javafx-sdk-25.0.3\lib
   > build_with_javafx.bat


RUN -- CONSOLE MODE
-------------------
> java -cp out agritwin.Main


RUN -- GUI MODE (after building with JavaFX)
--------------------------------------------
> java --module-path "%JAVAFX_LIB%" --add-modules javafx.controls -cp out agritwin.Main --gui
